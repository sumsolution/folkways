# folkways

A team framework for AI coding agents. It gives a 3–8 person engineering team shared skills,
knowledge, status tracking and working conventions (review, commits and PRs, research, handoffs)
on Claude Code and Copilot CLI.

**Status:** design stage. No code yet.
